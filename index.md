# Brainless Software

Software for which you do not need a brain to use

* [qppte](https://brainless-software.github.io/qppte/) - Embeddable code editor for Python.
* [i2c_api](https://github.com/Brainless-Software/i2c_api) - Abstract Python API for talking to I2C devices. 
* [CurrentProjectSwitcher](https://github.com/Brainless-Software/CurrentProjectSwitcher) - Minimal IntelliJ project switcher plugin
